## مشخصات فنی

### ظاهر سکشن‌ها
- هر سکشن: **یک دکمه اصلی** با آیکون + متن کوتاه
- کلیک روی دکمه → **dropdown زیرش** با زیرمجموعه‌ها
- سکشن‌ها با **خط جداکننده** (|) از هم جدا بشن
- رنگ پس‌زمینه dropdown: `#1a1a2e` (تم تیره)
- رنگ hover: `#00ffcc33`
- فونت: همون فونت فعلی (inherit)
- راست‌چین (RTL)

### قطعات جدید — مشخصات

#### مبل (Sofa)
- ۲نفره: `160×80cm` — مستطیل ساده + تکیه‌گاه
- ۳نفره: `220×80cm` — مستطیل ساده + تکیه‌گاه
- ال‌شکل: `L-shape 220×160cm`

#### صندلی (Chair)
- غذاخوری: `45×45cm`
- اداری: `50×50cm` + پایه
- میزبان: `60×60cm` + دسته

#### تخت (Bed)
- یک‌نفره: `90×200cm`
- دو‌نفره: `160×200cm`
- کودک: `70×140cm`

#### کمد (Cabinet)
- دیواری: `120×40cm` — بالای سینک
- زمینی: `120×60cm` — زیر سینک
- لباسی: `180×60cm`

#### قفسه (Shelf)
- کتابخانه: `120×30cm`
- دیواری: `80×20cm`

#### آینه (Mirror)
- دیواری: `60×80cm`
- قدی: `40×150cm`

#### توالت (Toilet)
- `40×70cm` — مستطیل + دایره کاسه

#### وان (Bathtub)
- `170×75cm` — مستطیل گردگوشه

#### روشویی (Sink-Bath)
- `55×45cm` — نیم‌دایره روی دیوار

#### سینک آشپزخانه (Kitchen Sink)
- `80×50cm` — مستطیل + دایره

#### اجاق (Stove)
- `60×60cm` — مربع + ۴ دایره

#### یخچال (Fridge)
- `70×70cm` — مربع + خط وسط
