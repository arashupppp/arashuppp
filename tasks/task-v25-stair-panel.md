# HOVI v25 — پنل ویرایش گرافیکی پله (جایگزین promptهای دابل‌کلیک)

## هدف
دابل‌کلیک روی پله در پلان 2D به‌جای ۳ پاپ‌آپ خام `prompt()`، یک پنل گرافیکی باز کند — هم‌سبک و هم‌استایل پنل موجود `openDoorEdit` (ویرایش درب).

## فایل هدف
`/root/hovi/editor_v1.html` — **فقط همین فایل**. تغییر دیگر فایل‌ها ممنوع.

## شرح تغییر

### ۱) تابع جدید `openStairEdit(st)`
- محل پیشنهادی: درست **بعد از** تابع `function openDoorEdit(op){...}` (پایانش: `p.querySelector('#dcx').onclick=()=>p.remove();\n}`).
- استایل دقیقاً مثل openDoorEdit: `position:fixed;top:70px;left:50%;transform:translateX(-50%);z-index:60;background:#111;border:1px solid #00ffcc66;border-radius:12px;padding:14px 18px;color:#ddd;font-size:13px;box-shadow:0 10px 40px #000d;min-width:340px`
- عنوان: `<b style="color:#00ffcc">ویرایش پله</b>`

### ۲) محتوای پنل
- **ردیف نوع (۵ دکمه، کلاس `sttbtn`):** `straight`=مستقیم / `L`=دربست L / `U`=دربست U / `J`=دربست J / `spiral`=مارپیچ
  - دکمهٔ نوع فعلی active: `background:#00ffcc33;color:#00ffcc` مثل dtbtn
- **فیلدها (فقط برای نوع فعلی مرتبط):**
  - مارپیچ: قطر (متر) = `(st.r*2)`، ارتفاع (متر) = `st.h`، جهت چرخش (دکمهٔ toggle: پادساعتگرد ↺ / ساعتگرد ↻)
  - مستقیم/L/U/J: عرض (متر) = `st.w`، ارتفاع (متر) = `st.h`، جهت صعود (دکمهٔ toggle: از شروع به انتها ↓ / برعکس ↑)
- **دکمه‌ها:** `تأیید` (id=`stok`, سبک دکمهٔ dok) و `بستن` (id=`stcx`, سبک dcx)
- input ها: `type=number step=0.05`، سبک هم‌سان dw (width:70px;background:#000;border:1px solid #345;...)

### ۳) رفتار دکمه‌های نوع
- تغییر نوع **زنده** روی پله اعمال می‌شود (بدون نیاز به تأیید): `tmpType` و رفرش visual ردیف دکمه‌ها مثل dtbtn
- **تبدیل بین انواع غیرمارپیچ (straight↔L↔U↔J):** نقاط موجود حفظ شود:
  - straight→L/U/J: `a` و `b` فعلی → `a`,`b`؛ `c` = نقطهٔ عمود پیش‌فرض از `b` به فاصلهٔ `w` (perpendicular پیش‌فرض سمت راست بردار a→b)
  - L/U/J→straight: `a` بماند؛ `b` = دورترین نقطه از `a` بین `b`,`c`
- **تبدیل به/از مارپیچ:** مارپیچ جدید مرکزش = مرکز جعبهٔ محاطی نقاط فعلی، `r=0.9`، `turn` حفظ یا ۱
  - مارپیچ→غیرمارپیچ: `a`=نقطهٔ فعلی مارپیچ، `b` = `a + [r*2, 0]`، `w=1`، `c` مثل قاعدهٔ بالا
- هنگام تبدیل نوع: `pushUndo()` **یک‌بار در لحظهٔ اولین تغییر نوع** (نه هر کلیک)

### ۴) رفتار تأیید/بستن
- `stok` → `pushUndo()` (فقط اگر مقداری عوض شده باشد؛ ساده: همیشه قبل از اعمال، ولی اگر هیچ تغییری نبود push نکن)؛ سپس:
  - مارپیچ: `r = clamp(قطر/2, 0.25..1.25)`, `h = clamp(0.5..6)`, `turn` از toggle
  - سایر: `w = clamp(0.4..3)`, `h = clamp(0.5..6)`, `dir` از toggle
  - `refresh(); showHint('پله به‌روز شد ✓'); p.remove();`
- `stcx` → اگر تغییری اعمال شده (نوع عوض شده) دست نزن (تغییر می‌ماند — مثل رفتار فعلی تغییر نوع درب)، فقط `p.remove()`
- **Escape** نیز پنل را ببندد (listener روی document، فقط تا زمان باز بودن پنل؛ از تداخل با Esc ابزار نصب جلوگیری شود — پنل event را stopPropagation کند)

### ۵) اتصال در dblclick
در `cv.addEventListener('dblclick', ...)` بلوک پله (`if(st){...}`) **کاملاً جایگزین شود** با:
```js
if(st){ openStairEdit(st); return; }
```
- رفتار فعلی pickElevW و pickOpening بعد از آن **دست‌نخورده** بماند.

### ۶) ممنوعیت‌ها
- هیچ فیلد/رفتار دیگری از ادیتور تغییر نکند
- تبدیل نوع نباید id پله را عوض کند
- undo نباید چندتایی شود (هر باز/بستن پنل حداکثر یک pushUndo برای تبدیل نوع + حداکثر یکی برای تأیید)
- کلیدهای R (جهت) و F و بقیهٔ شورتکات‌ها دست نخورده بمانند
- فایل‌های دیگر (m3, TPL, tests) تغییر نکنند

### ۷) تست پذیرش (Playwright headless — فایل `/tmp/pwshot/test_v25_panel.js`)
پایه: کپی از `/tmp/pwshot/test_v23d.js` (همان پروژهٔ پایه با پله) و:
1. باز کردن editor، نصب پلهٔ مستقیم (کلیک‌ها همان مختصات تست v23d)
2. دابل‌کلیک روی پله → assert: پاپ‌آپ `prompt` **صورت نگرفته** (page.on('dialog') counter==0) و پنل با متن «ویرایش پله» visible
3. تغییر عرض به 1.4 → تأیید → assert عرض پله در `proj.stairs[0].w==1.4`
4. دوباره دابل‌کلیک → کلیک دکمهٔ «مارپیچ» → assert نوع spiral و پنل حالا فیلد قطر دارد
5. تأیید → assert `st.r>0` و `st.turn∈{1,-1}` و `refresh` بدون خطای کنسول
6. دوباره دابل‌کلیک → Escape → assert پنل بسته شد
7. undo (Ctrl+Z) → assert برگشت به نوع قبلی (یا حداقل تعداد stairs تغییری نکرده و خطا نبود)
8. **کل اجرا بدون هیچ console error** (صفحهٔ اصلی)
- خروجی موفق: چاپ `V25-PANEL-OK`

نکتهٔ اجرا: `node /tmp/pwshot/test_v25_panel.js` باید exit code 0 بدهد.
